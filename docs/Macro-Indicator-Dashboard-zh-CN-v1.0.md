# 宏观指标监控仪表盘 v1.0

## 目的 Purpose

Macro Indicator Dashboard 用于建立全球宏观环境的系统化监测体系。

目标不是简单收集数据，而是判断当前宏观状态以及变量之间的传导机制。

---

# 1. 增长指标 Growth Indicators

## 美国

核心指标：

- GDP增长
- ISM制造业PMI
- ISM服务业PMI
- 工业生产
- 零售销售
- 消费者信心
- 非农就业
- 初请失业金

关注问题：

- 经济动能是在增强还是减弱？
- 消费是否可持续？
- 劳动力市场压力是否增加？

## 中国

核心指标：

- GDP
- 工业增加值
- 社会消费品零售总额
- 固定资产投资

- 房地产数据
- 信贷增长

关注问题：

- 增长主要来自供给还是需求？
