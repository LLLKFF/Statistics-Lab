# Monthly Macro Regime Report

## Purpose

Monthly Macro Regime Report evaluates whether the global economic environment has entered a new phase.

The focus is not short-term market movement, but changes in the underlying macro regime.

## Research Structure

1. Executive Summary
2. Macro Regime Assessment
3. Growth Analysis
4. Inflation Analysis
5. Monetary Policy Environment
6. Global Liquidity Conditions
7. Asset Allocation Implications
8. Key Risks and Scenarios
9. Previous View Review

## Core Question

> Has the macro environment changed enough to require a revision of the research framework?
