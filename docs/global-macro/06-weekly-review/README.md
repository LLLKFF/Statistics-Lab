# Weekly Macro Review

## Purpose

Weekly Macro Review is the medium-frequency research layer of Global Macro Lab.

It is not a collection of daily news summaries. Its purpose is to answer:

> What changed in the global macro environment this week, why did it change, and what does it mean for financial markets?

## Research Structure

Each weekly letter follows:

1. Weekly Macro Summary
2. Changes in Macro Regime
3. Economic Data Review
4. Central Bank Watch
5. Market Review
6. Institutional Debate
7. Asset Market Implications
8. Next Week Watchlist

## Writing Principle

Focus on mechanisms rather than events.

A weekly report should explain:

Economic conditions → Policy response → Financial conditions → Asset prices
