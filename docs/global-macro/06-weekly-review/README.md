# Weekly Macro Review

Weekly Macro Review 是 Global Macro Lab 的周频研究层。它不重复日度新闻，而是把 Research Diary 中已经核验的事实、机制判断与反证条件压缩成一张可持续更新的周度宏观状态图。

## 固定输出字段

每期周报至少保留：

1. 观察窗口与信息边界；
2. 一句话结论；
3. 增长、通胀、政策、金融条件和资产状态；
4. 本周判断更新；
5. 跨资产传导链；
6. 当前 Thesis、支持证据与失效条件；
7. 下一验证清单；
8. 研究状态、证据等级与来源入口。

## 使用原则

- 只复用已经核验的日记、数据面板和研究本，不另造平行口径；
- 区分事实、机构预测与 Statistics Lab 推断；
- 周报负责回答“本周改变了什么”，日记负责保留当时的信息边界；
- 未执行因果识别时，跨资产共振只写为机制推断；
- 历史判断保留，后续变化通过新一期周报与 Git 历史记录。

## English summary

Weekly Macro Review is the medium-frequency synthesis layer of Global Macro Lab. It converts verified daily research into regime changes, transmission mechanisms, falsifiable theses and a forward validation checklist.
