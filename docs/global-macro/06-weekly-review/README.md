# Weekly Macro Review

Weekly Macro Review 是 Global Macro Lab 的周频研究层。它不重复日度新闻，而是把 Research Diary 中已经核验的事实、机制判断与反证条件压缩成一张可持续更新的周度宏观状态图。

## 固定工作流

1. 每期 Research Diary 完成事实核验并归档；
2. 将日报中的新增事实、判断变化和反证条件写入当周 Weekly Macro Review；
3. 不复制整篇日报，只保留对周度状态有增量的信息；
4. 若新日报推翻前期判断，明确记录“原判断—新证据—修正后判断”；
5. 周末完成最终汇总，并冻结当周信息边界；
6. 周末后的新信息进入下一周，不回填成当时已知事实；事实订正除外。

## 固定输出字段

每期周报至少保留：

1. 观察窗口与信息边界；
2. 一句话结论；
3. 增长、通胀、政策、金融条件和资产状态；
4. 本周判断更新；
5. 跨资产传导链；
6. 当前 Thesis、支持证据与失效条件；
7. 下一验证清单；
8. 研究状态、证据等级与来源入口。

## 使用原则

- 只复用已经核验的日记、数据面板和研究本，不另造平行口径；
- 区分事实、机构预测与 Statistics Lab 推断；
- 周报负责回答“本周改变了什么”，日记负责保留当时的信息边界；
- 日报完成后即更新当周周报，避免周末重新搜集和重复判断；
- 未执行因果识别时，跨资产共振只写为机制推断；
- 历史判断保留，后续变化通过周报修订记录与 Git 历史追踪。

## English summary

Weekly Macro Review is the medium-frequency synthesis layer of Global Macro Lab. Each completed Research Diary updates the current weekly evidence ledger; the final weekly edition records regime changes, transmission mechanisms, falsifiable theses and the next validation checklist.
