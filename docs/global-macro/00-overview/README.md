# Global Macro Lab

Global Macro Lab 是 Statistics Lab 的核心研究模块之一。

目标：利用统计方法研究全球经济周期、货币政策、金融条件与资产价格之间的关系。

核心研究链：

Economic Conditions

↓

Policy Response

↓

Financial Conditions

↓

Capital Flows

↓

Asset Prices

## Modules

- Framework: 宏观研究框架
- Dashboard: 宏观数据面板
- Institutions: 机构研究追踪
- Analysts: 宏观思想库
- Research Diary: 日常研究记录
- Weekly Review: 周度复盘
- Monthly Report: 宏观状态报告
- Data Notebook: 数据分析与模型研究
