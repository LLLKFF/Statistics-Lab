# Global Macro Research Diary #010

## 和平方案被拒，油价重返107美元：一次反证如何重新抬高利率路径

观察日期：2026年9月28日｜系列：Statistics Lab · Global Macro Lab｜模式：Major Event Mode｜信息边界：截至2026年9月28日美国常规交易收盘后可获得的官方文件、正式结算与公开市场信息

9月28日最重要的新信息不是美股下跌0.8%左右，而是上周五刚刚出现的能源缓和路径在一个周末内被反转。美国总统特朗普拒绝伊朗提出的分阶段恢复霍尔木兹海峡通行方案，尽管双方仍准备本周继续谈判；Brent随即上涨3.4%至107.86美元，重新站上#009事先写明的107美元失效线。S&P 500收于7,683.69点，下跌0.77%；Nasdaq收于26,820.38点，下跌0.92%。NYSE下跌家数约为上涨家数3.55倍，Nasdaq为2.56倍，新低数量分别达到29只和249只。[^1][^2] 这不是一项可以被“仍在谈判”轻轻带过的变化：市场重新面对的是能源冲击延长、Fed再次加息概率升高，以及极高真实资本成本从估值约束转成更广泛风险传播的组合。

利率分解使这条链条更清楚。美国财政部9月28日官方曲线显示，2年期CMT由4.81%升至4.92%，10年期由5.17%升至5.24%，30年期由5.49%升至5.56%；同日10年期实际CMT由2.83%升至2.90%。用同日、同期限名义CMT减实际CMT作描述性近似，10年期通胀补偿仍约2.34%，与上周五基本相同。[^3][^4] 因而当天长端上行并不是长期通胀补偿突然失控，而更接近实际利率、期限风险与政策路径共同抬高真实资本成本。黄金在现货市场下跌3.9%至约4,119.55美元，也与“更高实际利率压过避险需求”的解释一致。[^2]

### 一、重大事件扫描：美伊方案被拒触发Major Event Mode，能源重新成为政策变量

过去24小时内已经发生足以重塑能源、通胀与金融条件的Tier-1事件，因此本期进入Major Event Mode。伊朗在联合国大会期间提出分阶段安排：在美国降低军事压力并解除对伊朗港口封锁的条件下，恢复霍尔木兹海峡正常通行；特朗普周末确认拒绝该方案，但表示谈判仍将继续。[^1][^5] 这同时删除了两个过度简化的结论：美国拒绝方案不等于外交路径永久关闭，继续谈判也不等于实物流量已经恢复。对市场真正有意义的仍是船舶通行、保险费率、出口装载与成品油供应，而不是单独一句政治表态。

未来36小时内，澳洲联储9月29日决议是主要央行事件，市场基准预期是加息25bp至4.60%。[^6] 美国同日JOLTS职位空缺会检验劳动力需求；严格按36小时计算，9月30日8:30公布的8月PCE略超出窗口，但它仍是下一项最关键的美国政策验证。BEA同时将公布二季度GDP第三次估计与年度修订。[^7] 本期不提前押注PCE结果，只记录Reuters根据CPI/PPI形成的基准：8月核心PCE环比约0.3%、同比约3.4%。[^8]

### 二、事件时间线：从七日通行方案，到周末拒绝，再到周一重新定价

上周早些时候，伊朗释放七日内恢复海峡正常通行的提议，Brent一度跌破100美元；9月25日，谈判希望仍在，Brent回落至约104.40美元，#009据此冻结了温和偏空判断，但同时把“美国拒绝方案、通行继续恶化，或Brent重新站上107美元”写成明确失效条件。周末特朗普拒绝提案后，周一Brent直接升至107.86美元；美国10年期二级市场收益率盘中一度升至5.26%左右，30年期触及2004年以来高位，之后随油价从日内高位回落而部分收窄涨幅。[^2]

权益反应也呈现清楚的阶段差异。开盘后的第一轮交易是油价上升、收益率上行与指数下跌；盘中油价和收益率从高位回落，指数跌幅随之收窄，但没有回到平盘。Nvidia逆势上涨1.6%，与其1,500亿美元回购授权有关，却仍无法抵消更广泛的估值与成本冲击；Boeing因737 MAX 10认证推迟下跌6.9%，Tesla因J.P. Morgan下调目标价下跌3.9%。[^1] 因此，收盘不是单一宏观因子造成的“纯事件研究”，但宽度、新低数量和跨行业下跌说明能源—利率冲击已经超过个别公司利好能够完全覆盖的范围。

### 三、Event Decomposition：市场在交易四件事，而不只是“战争风险”

第一层是能源供应路径surprise，方向显著偏鹰。#009的基准是谈判选择权可能压低Brent，但美国拒绝方案意味着这一选择权不能再按上周五的概率定价。价格从104.40升至107.86并不是油价永久上行的证明，却足以恢复短期通胀与运输成本尾部风险。

第二层是Fed反应函数surprise。利率期货把10月加息至少25bp的概率推到约70.3%，高于一周前的57.6%和一个月前的17.7%。[^1] 这不是因为Fed承诺跟随油价机械加息，而是经济仍有韧性、劳动力市场尚未明显失衡，能源和AI投资又同时增加短期需求与价格压力。市场因此提高了“Fed还有空间继续收紧”的权重。

第三层是实际利率与期限风险surprise。10年期名义CMT上涨7bp、实际CMT同样上涨7bp，而描述性通胀补偿保持约2.34%。[^3][^4] 这意味着市场并未简单交易长期通胀预期脱锚，而是在要求更高的真实回报，并把政策持久性、财政供给与宏观不确定性放进长端价格。对股票而言，2.90%的实际10年期收益率比“油价上涨”更接近共同估值约束。

第四层是AI增长—通胀组合。美联储理事Lisa Cook当天在官方演讲中指出，AI相关投资在短期推高芯片、电脑、软件、建筑劳动力与能源需求，企业已宣布约2万亿美元投资计划、但只支出很小一部分；生产率红利可能在未来几年带来温和通胀缓解，却来不及抵消今年稍后更广泛的价格压力。她同时确认支持9月加息25bp，并预计AI建设、油价和中东供应链扰动会继续给通胀施压。[^9] 这使“AI利好股票、能源利空股票”的简单二分法失效：AI既是盈利和增长支撑，也可能延长高利率环境。

### 四、5.24%名义、2.90%实际：市场仍在重估真实资本成本

财政部曲线显示，9月28日2Y、3Y、5Y、7Y、10Y分别为4.92%、5.01%、5.06%、5.15%和5.24%，较上周五分别上涨11bp、7bp、8bp、9bp和7bp；30Y升至5.56%。[^3] 2Y—10Y利差由36bp收窄至32bp，说明前端对政策路径的重新定价略强于长端。Reuters记录的二级市场10Y约5.26%、30Y约5.576%，高于财政部约3:30的标准化CMT；本文用官方CMT做Ledger验证，用Reuters报价描述交易时段，两种口径不混用。[^2]

实际曲线同样全面上行：5Y由2.64%升至2.73%，7Y由2.73%升至2.80%，10Y由2.83%升至2.90%，20Y由3.08%升至3.14%，30Y由3.22%升至3.28%。[^4] 这说明油价冲击并未只进入通胀补偿，市场更担心的是Fed需要维持更高政策利率、强增长继续吸收资本，以及长久期资产需要更高回报。若未来PCE低于预期而实际10Y仍不能回落，期限风险和融资供需将获得更大解释权；若名义、实际与加息概率同时回落，则今天的上行更可能是事件冲击而非新平台。

### 五、市场宽度确认压力扩散，但Nvidia提醒我们不能把指数写成单一宏观交易

S&P 500当日跌幅为8月20日以来最大，11个行业中风险压力广泛扩散；NYSE和Nasdaq的下跌家数显著多于上涨家数，Nasdaq 249只新低远高于40只新高。[^1] 这组宽度比指数跌幅更重要，因为它说明高油价与高实际利率已经开始影响更多资产，而不是只压制一两个高估值板块。

但Nvidia上涨1.6%同样是事实。公司级现金流、回购和盈利信息可以让头部AI资产在宏观压力下继续表现，这也是为什么不能把Nasdaq下跌0.92%直接归因于AI故事结束。更准确的判断是：当实际10Y达到2.90%、30Y接近5.6%时，市场对远期现金流的折现更严格，只有能迅速兑现盈利或提供资本回报的公司可以部分抵抗。BlackRock 9月28日公开周评也认为市场对进一步加息的定价可能过度，但同时强调AI盈利能否持续覆盖更高融资成本将决定风险资产韧性。[^10]

### 八、Model Update：能源信号从“价格趋势”升级为“事件状态×实物确认”

第一，Energy factor不再只看Brent方向。后续必须同时记录外交事件状态、海峡通行、保险与运费、出口装载、期限结构以及柴油/航煤裂解；政治表态改变情景权重，实物流量决定冲击是否持久。#009的失效说明，只看上周五价格回落会低估周末跳空风险。

第二，Rates factor继续拆成政策前端、实际利率、通胀补偿和期限风险。今天10Y名义与实际同升7bp、通胀补偿近似不变，说明“油价上涨=breakeven上升”的机械映射不成立。后续PCE若降温但实际利率不降，就要提高期限风险和资本供需的权重。

第三，Breadth从风险传播指标升级为方向确认。#009中性指数判断未计分，但周一NYSE 3.55:1、Nasdaq 2.56:1的下跌宽度与249只新低，显示宏观冲击已从边缘资产传到更广范围；只有权重股现金流仍在延缓指数跌幅。

第四，AI factor拆成“短期需求通胀”和“中期生产率供给”。Cook的官方演讲给出了清晰时间差：建设阶段消耗能源、劳动力和资本，生产率缓解则需要更长扩散期。未来不能把AI一律视为通缩，也不能因为短期通胀就否定长期供给收益。

### 九、Event Watch：RBA在36小时窗口内，PCE是随后最强验证

澳洲联储的基准预期是加息25bp至4.60%。真正的分歧变量不是单次加息，而是声明是否把能源、工资与服务通胀描述为需要连续收紧，以及澳元、澳债与全球前端利率是否出现共振。若RBA只完成预期动作、没有强化路径，全球影响可能有限；若反应函数明显更鹰，主要央行同步紧缩的定价会获得新证据。[^6]

美国PCE将在9月30日8:30公布。当前可核验的Reuters基准是核心PCE环比约0.3%、同比约3.4%，但本次包含方法调整，数据解读需要同时观察修订。[^7][^8] 对市场而言，最重要的不是单一同比，而是核心服务、实际消费和收入能否回答三个问题：能源冲击是否开始扩散，需求是否仍足以吸收更高利率，Fed是否需要在10月继续行动。若核心PCE低于基准、实际消费降温且收益率回落，#010对10Y与美元的+1将失效；若核心通胀粘性、消费仍强，2.90%的实际10Y可能成为新一轮估值压力的起点。

### 十、Statistics Lab View：错误判断已经被市场推翻，但研究框架因此更完整

截至9月28日收盘，我们更支持的解释是：美伊方案被拒重新打开能源通胀尾部风险，而强经济和AI投资使Fed仍有空间回应；市场因此主要通过实际利率和政策路径提高真实资本成本，而不是通过长期通胀补偿失控来定价。S&P和Nasdaq下跌、宽度恶化、黄金大跌与名义/实际收益率同步上行，都与这条解释一致，但单日共振不能被写成严格因果识别。

证据不足之处也很明确。美伊谈判仍将继续，Brent 107.86美元尚未得到更差实物流量的确认；PCE和JOLTS尚未公布，2.90%的实际10Y也只有一天观察。BlackRock认为市场对后续加息可能过度，这一机构分歧需要用数据而不是态度解决。[^10]

最重要的验证条件是：海峡通行和成品油是否继续恶化；10Y实际收益率能否站稳2.90%以上；PCE是否达到或超过核心环比0.3%的基准；市场新低是否继续增加并拖累头部AI。最重要的反证则是可执行的美伊安排落地、Brent回到104美元以下、核心PCE与实际消费同时降温，以及实际10Y跌破2.80%。若这些反证共同出现，当前“能源—利率—估值”链条必须下调权重。

Forecast Loop今天给出的最重要结论，不是#007终于在3D窗口里得到验证，而是#009的Brent -1在1D就被明确推翻。失败样本不删除，失效条件也不事后移动；只有这样，未来的Weekly Forecast Audit才有可能区分研究能力、运气与情景风险。
