# Global Macro Research Diary #004

## 加息不等于货币走强：BoJ、5%美债与全球紧缩的第二阶段

观察日期：2026年9月18日｜系列：Statistics Lab · Global Macro Lab｜模式：Major Event Mode｜信息边界：截至2026年9月18日美国常规交易收盘及当时可获得的官方文件、正式结算与公开市场信息

过去三天，全球主要央行几乎把同一个问题摆到了市场面前：当能源冲击重新抬高通胀尾部风险，而增长又没有明显坍塌时，货币政策究竟需要多快、多久地维持偏紧状态？9月16日，美联储把政策利率上调25个基点，并通过SEP把更高的利率路径推向2027年；9月17日，英国央行维持Bank Rate在3.75%，却用更偏鹰的通胀判断和更温和的QT安排把“政策利率”与“长期金融条件”分开处理；9月18日，日本银行进一步把无担保隔夜拆借利率目标上调至1.25%，创31年来最高水平。表面上看，这是一次全球央行同步收紧，但真正值得研究的不是“谁又加息了”，而是同样的25个基点为什么在不同市场产生了完全不同的价格反应。[^1]

今天最有信息量的现象恰恰发生在日本：日本银行加息后，日元没有走强，反而明显贬值。官方外汇数据表明，美元兑日元从东京时间9:00的156.15–156.17升至17:00的157.48–157.50；Reuters随后记录到美元兑日元盘中最高升至158.05。[^2][^3] 这说明市场并没有把“加息”本身视为新的鹰派信息。25个基点已经被高度定价，真正决定汇率的是市场对后续加息速度、委员会内部一致性以及日美利差未来路径的重新判断。日本银行在声明中明确说，底层CPI正接近2%，金融条件在加息之后仍将保持宽松，未来还会继续提高政策利率；植田和男在记者会上甚至表示政策阶段已经发生变化，也不排除连续加息或单次50个基点的可能。可是与此同时，两名委员投票反对本次加息，植田拒绝给出明确的下一次行动时间表，市场因此得到的是“中期方向更鹰、短期节奏仍不确定”的组合。对于已经提前买入加息预期的日元多头来说，这个组合仍然不够。[^1][^3]

因此，9月18日的核心结论不是“BoJ不够鹰”，更不是“加息失效”，而是全球紧缩正在进入第二阶段：**市场不再只交易政策动作，而是在交易央行的反应函数、实际资本成本和政策可信度。** 这也是今天美国利率市场给出的第二个重要证据。美国财政部同日官方曲线显示，2年期国债收益率由前一日4.67%升至4.76%，10年期由4.94%升至5.01%；与此同时，10年期实际收益率由2.61%升至2.68%。用同期限、同日期的名义CMT减去实际CMT做一个描述性近似，9月17日和18日的10年期通胀补偿都约为2.33%。这不是精确的零息breakeven测算，但足以说明今天10年期收益率重新站上5%时，新增压力几乎全部来自实际利率，而不是通胀补偿进一步失控。[^5][^6] 对资产定价而言，这比单纯说“市场担心通胀”更重要：市场正在要求更高的真实资本回报。

### 一、BoJ加息后的日元走弱，说明市场交易的是“下一步”而不是“这一步”

9月18日的日本银行会议使今天进入Major Event Mode。官方决定是把无担保隔夜拆借利率目标从1.00%提高到1.25%，投票结果7比2，新利率自9月24日起生效；补充存款便利利率同步设为1.25%，基本贷款利率提高到1.50%。[^1] 如果只看这个动作，它并不意外。会议前掉期市场已经给出较高加息概率，而且当天早些时候公布的8月全国CPI也没有提供足够强的理由让日本银行推迟行动：日本总CPI同比1.9%，剔除生鲜食品后的核心CPI同比1.7%，低于市场预期的1.8%，但剔除生鲜和能源后的指标仍同比1.9%。[^4] 核心CPI低于2%并没有阻止加息，因为日本银行当前关心的不只是当月读数，而是工资、企业定价、进口成本和通胀预期是否正在形成更持续的价格循环。

官方声明的逻辑比标题更鹰。日本银行指出，生产者价格仍因AI相关需求、高油价和日元贬值而维持较高同比增幅，企业间价格上涨正在向消费价格传导，工资上涨向售价转嫁的行为仍在继续，中长期通胀预期也继续上升。它进一步判断底层CPI正在接近2%，并明确写出未来将“继续提高政策利率、调整货币宽松程度”，同时强调即便这次加息之后，日本的金融条件仍然宽松。[^1] 这已经不是过去那种“为了摆脱通缩而谨慎正常化”的语言。植田在发布会上把变化说得更直接：政策阶段已经从推动通胀升向目标，转向防止底层通胀超调；他不排除连续加息，也不排除在必要时单次加息50个基点，但希望通过更早、更小的动作避免将来被迫大幅收紧。[^3]

问题在于，市场并不是只读方向，还要给节奏定价。本次两名反对票来自Toichiro Asada和Ayano Sato。Asada认为近期剔除生鲜食品的CPI仍低于2%，经济强度不足以证明现在必须加息；Sato则认为经济与物价并未明显较此前加速，因此当前加息并不合适。[^1] 两张反对票让市场看到，未来每一步仍需要跨越内部阻力。植田同时拒绝预判终端利率和固定加息节奏，于是市场很自然地把“加息已经发生”和“下一次加息是否很快到来”拆开交易。

这就是为什么日元会出现看似反常的反应。日本银行金融市场局数据显示，美元兑日元从9:00 JST的156.15–156.17升至17:00 JST的157.48–157.50；Reuters报道，纽约时段美元一度升至158.05，随后日本当局进行汇率询价后涨幅收窄。[^2][^3] 对日元来说，今天真正的surprise并不是政策利率上调，而是“加息已兑现，但后续节奏没有比市场预期更明确”。与此同时，美联储刚刚把未来政策路径向上重定价，日美利差收窄的速度仍然不够快。只要这个差异存在，日本仍然会面对进口通胀、能源成本和汇率之间的反馈回路，也就意味着BoJ未来的政策压力并没有随着本次加息而结束。

### 二、美国10年期重新站上5%，但今天更像“实际利率冲击”而不是新一轮通胀失控

如果把今天的市场只概括成“BoJ加息导致全球收益率上涨”，会漏掉最重要的一层。美国财政部9月18日官方日终数据已经更新，因此今天可以用完全对齐日期和期限的口径做分解。2年期名义CMT由9月17日的4.67%升至4.76%，10年期由4.94%升至5.01%；10年期实际CMT同时由2.61%升至2.68%。[^5][^6] 也就是说，10年期名义收益率上行7个基点，10年期实际收益率同样上行7个基点，而用两者做同日、同期限的简单差值得到的近似通胀补偿仍约为2.33%。

这组数据与9月16日FOMC之后的市场逻辑是连续的。市场并没有在今天突然相信未来十年的平均通胀会进一步失控，而是在给更高的真实资本成本重新定价。美联储已经明确表示当前金融条件并不算特别限制，SEP也把未来几年的政策利率中位数整体上移；BoJ今天再度加息，又强化了“全球超低利率资产继续减少”的叙事。长期债券因此不仅需要补偿通胀，还需要补偿更高的真实资金需求、全球资本开支、财政融资和更不确定的政策路径。

这一点对风险资产尤其关键。10年期名义收益率在5%左右本身已经很高，但真正改变估值的，是其中有接近2.7%的实际收益率。对不产生现金流的资产、远期现金流占比较高的成长股、房地产和高杠杆企业而言，实际利率才是更直接的折现率压力；对于现金流强、利润率高、融资依赖较低的公司，高实际利率虽然压缩估值，却未必立即破坏盈利。因此今天美国股市出现了非常典型的“指数看起来稳定、内部却更选择性”的结构。

Reuters数据显示，标普500收涨0.17%，纳斯达克上涨0.40%，道琼斯下跌0.18%；但NYSE下跌家数约为上涨家数的1.78倍，Nasdaq下跌家数也明显更多，成交量达到252.9亿股，远高于过去20个交易日平均的161.9亿股。[^7] 科技板块领涨，而公用事业表现最弱。换句话说，指数没有因为5%美债立刻下跌，不代表高利率失去影响，而是盈利确定性和AI相关增长仍在帮助少数高质量资产吸收更高折现率。市场从“买一切”向“买能证明现金流”的方向进一步分化。

### 三、美国工业生产提醒我们：AI投资很强，不等于制造业整体没有利率敏感性

9月18日另一个重要数据来自美联储G.17。8月美国工业生产环比持平，7月为增长0.2%；制造业产出环比下降0.3%，而市场此前预期增长0.3%。采矿业增长0.1%，公用事业增长1.8%，总工业生产同比仍增长1.4%；产能利用率维持在76.3%，比1972—2025年长期均值低3.1个百分点。[^8] 这组数据没有给出衰退信号，但它明确提醒市场：增长韧性并不意味着所有行业都能无视融资成本和能源成本。

制造业内部的结构更有意思。汽车及零部件产出下降1.2%，电脑和外围设备下降1.4%；通信设备增长0.8%，半导体及相关电子元件环比小幅下降0.1%，但同比仍增长12.4%。[^9] 这正是当前美国经济最典型的“双速结构”：AI、数据中心、通信基础设施和部分高端电子链条仍然保持很强的资本开支需求，但传统耐用品、住房和其他利率敏感部门已经在高融资成本下承压。

这也解释了为什么Fed能够继续讨论加息，而市场却没有直接交易衰退。只要就业、消费和AI资本开支能支撑总量增长，美联储就有空间优先处理价格稳定；但如果高实际利率开始从住房扩散到制造业、企业信贷和就业，政策空间会迅速变窄。今天的工业生产还不足以证明这种扩散已经形成，但它提供了一个必须跟踪的边界条件：未来几个月如果传统制造业进一步放缓，而高科技制造也从同比强势转向明显减速，那么“增长足够强、可以承受更高利率”的核心前提就会被削弱。

### 四、油价连续回落，但实物供应链还没有恢复正常

过去两天风险资产得到喘息，能源价格回落是重要原因。9月18日Brent结算于104.87美元/桶，下跌0.93%；WTI结算于100.30美元/桶，下跌1.58%。[^10] 直接催化来自外交和供应替代消息：中国在沙特请求下敦促伊朗约束胡塞武装对沙特石油基础设施的袭击，市场同时期待沙特通过替代物流和修复East-West管线恢复更多供应。价格从本周高位回落，说明市场正在降低最极端的供应中断概率。

但这里不能把“油价跌了”写成“能源风险解除”。Reuters报道，霍尔木兹海峡的商业船舶通行仍显著低于正常水平，沙特East-West管线多个泵站受损，恢复一半运力可能需要数日，而完全恢复仍没有明确时间表；美国零售柴油价格仍处于创纪录水平。[^10] 这意味着原油期货价格回落与实体经济中的运输、炼化和成品油成本可能存在时滞。对Fed来说，真正重要的不是Brent一天跌1%，而是柴油、航空燃油、运价和企业投入成本是否持续回落，并最终不再向服务价格和工资谈判传导。

今天10年期近似breakeven没有上升，反而加强了一个暂时有利的解释：市场愿意相信本周的能源冲击至少没有继续恶化到需要上调长期通胀补偿。但这仍然是“没有进一步恶化”，不是“问题已经解决”。如果周末地缘事件重新破坏实物流量，油价回到本周高点甚至更高，那么Fed、BoJ和BoE当前偏鹰的反应函数会立刻获得新的支撑。

### 五、跨资产真正的共同变量不是“risk-on / risk-off”，而是资本成本与流动性价格

今天的跨资产表现非常适合说明为什么不能用简单的risk-on / risk-off框架解释市场。美股指数温和上涨，但市场宽度偏弱；美元兑日元大幅走强；黄金上涨；比特币也明显反弹；油价下跌；美国实际利率上升。Reuters报道比特币当天上涨约5.9%至8.1万美元附近，黄金现货一度上涨约1.2%至4390美元附近。[^7][^12] 如果硬把这些资产放进同一个“风险偏好”故事里，会出现明显矛盾。

更合理的解释是，不同资产在交易不同的边际变量。日元在交易BoJ未来加息节奏与日美利差；黄金一方面受到高实际利率压制，另一方面仍受地缘风险和油价回落后的仓位调整支持；比特币的反弹还有前期抛售后的仓位与资产特定因素；科技股则继续受AI盈利与资本开支支撑。共同背景是“资金价格变贵”，但各资产对这个背景的敏感度、现金流结构和自身催化并不相同。

这也与几家机构最新公开观点形成有价值的交叉验证。Goldman Sachs在FOMC后通过Reuters公开转述把10月再加25个基点纳入基准预测，理由是委员会对更快回到2%目标的偏好明显增强；这属于媒体转述的机构预测，而不是我们读取到的完整客户报告。[^13] Morgan Stanley公开播客则直接把Warsh关于“移除一剂宽松”和金融条件仍不限制的表述视为政策可能继续收紧的关键信息，其经济学团队现在预计12月和2027年3月各再加息25个基点。[^14] J.P. Morgan Asset Management的公开评论强调9月点阵图比6月更鹰，全球收益率因此整体向上移动；BlackRock 9月18日公开文章则认为高无风险利率和高实际收益率提高了固定收益的起始回报，同时在权益内部更偏好高质量、大盘和分红公司，而不是利率更敏感的小盘股。[^15][^16]

这些观点并不是同一个“共识”，但它们共享一个核心判断：未来资产回报更依赖对现金流质量、久期、融资结构和真实资本成本的区分。今天美股指数稳定、内部宽度走弱，正好是这种市场结构的即时版本。

### 六、这次BoJ会议到底改变了未来6—12个月什么认知

如果把9月16日至18日连续三天的央行事件放在一起看，市场对未来6—12个月的认知至少发生了三点变化。

第一，全球主要央行的政策中枢已经明显上移。美联储不再把当前利率视为明显限制，BoJ也明确说即使提高到1.25%金融条件仍然宽松，BoE虽然没有加息，却承认能源可能把通胀推得更高。全球市场过去很长时间习惯用“下一次降息什么时候来”组织定价，现在更现实的问题是“谁还要继续加、要加到哪里、要在高位停多久”。

第二，汇率将重新成为货币政策的重要传导渠道。BoJ加息后日元反而贬值，说明单次政策动作并不足以抵消巨大的利差和市场对未来路径的判断。弱日元又会推高进口成本，反过来增加BoJ进一步加息的压力。这种反馈如果持续，日元可能从一个被动结果变成政策约束本身。日本当局已经进行汇率询价，说明158附近的波动开始进入政策敏感区。[^3]

第三，5%美债正在从“市场恐慌数字”变成新的资本成本参照。9月18日10年期名义收益率5.01%、实际收益率2.68%，而近似通胀补偿并未继续上升。[^5][^6] 这意味着债券市场不只是担心物价，更是在要求更高的真实回报。只要这个状态持续，全球资产估值、房地产融资、企业债务再融资、财政利息负担和AI资本开支回报门槛都会被重新计算。

Statistics Lab当前更支持的解释是：**全球紧缩已经从“通胀预期冲击”逐步转向“真实资本成本重估”。** 这不是说通胀风险不重要，而是当前市场最关键的新变量已经变成：央行是否相信增长足够强，可以让实际利率在更高水平维持更久。今天美国名义和实际10年期收益率几乎同步上行，而breakeven大体稳定，是支持这一解释的最直接证据之一。

### 七、下一关键事件 / Event Watch：周末看中国LPR，更重要的是看能源和日元是否出现非线性变化

未来36小时没有新的FOMC、ECB、BoJ这类主要央行决议，但窗口内仍有一个需要跟踪的政策事件：中国将进行9月LPR报价。Reuters对21位市场参与者的调查显示，所有受访者都预计1年期LPR维持3.00%、5年期LPR维持3.50%不变。[^17] 因此，基准情景不是“突然降息”，而是中国继续在全球央行偏紧环境中保持相对克制。真正有信息量的surprise会是任何超预期调整，尤其是5年期LPR变化，因为它会直接影响房地产融资和居民资产负债表预期。

相比预期高度一致的LPR，周末更值得警惕的是两个非计划变量。第一个是中东能源供应链。如果霍尔木兹或沙特管线出现新的实物中断，Brent重新上破本周高点，那么市场对Fed、BoE、BoJ继续收紧的定价可能再次同步加强。第二个是日元。如果美元兑日元在日本当局已经进行汇率询价后仍持续向158甚至更高位置推进，市场就需要重新评估直接干预或更强政策沟通的概率。这里不提前下注政策动作，但价格本身已经进入需要验证的政策通道。

### 八、当前判断、证据不足与反证条件

目前最支持的解释是：9月18日并不是一次新的通胀恐慌，而是全球资本成本在一系列央行事件后完成第二轮重定价。BoJ加息但日元走弱，说明市场更在意后续路径而非单次动作；美国10年期重新回到5%，而同期限实际收益率同步升至2.68%、近似breakeven维持约2.33%，说明当天利率压力主要来自真实资本成本；美国工业生产持平、制造业下降0.3%，又提醒我们增长韧性存在明显行业分化，AI强并不等于所有部门都能承受更高利率。[^5][^6][^8]

证据仍然不足的地方主要有三处。第一，一天的实际利率分解不能证明未来几周的长端上行都由real yield主导，期限溢价、财政供给和通胀补偿仍可能重新变化。第二，日元贬值既有BoJ路径因素，也受到美元自身走强、仓位和汇率询价影响，不能把全部变动归因于两张反对票。第三，油价连续回落尚未完全传导到柴油、运输和企业成本，因此不能据此判断能源冲击结束。

未来会让我们调整当前判断的条件非常明确：如果Brent和柴油价格持续下行、核心通胀广度明显收窄，同时美国制造业、就业和实际消费转弱，那么“实际利率可以高位维持更久”的逻辑会被削弱，Fed进一步加息的必要性也会下降；反过来，如果油价重新冲高、日元继续贬值、日本通胀预期上升，而美国就业和AI资本开支仍然强，那么BoJ和Fed都可能被迫比当前市场基准更快收紧。对下一阶段而言，我们更关注这组可验证变量，而不是给“全球紧缩”贴一个永久标签。
