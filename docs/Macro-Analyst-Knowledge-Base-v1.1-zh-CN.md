# Macro Analyst Knowledge Base v1.1

## Purpose

本模块用于沉淀全球宏观领域重要机构、投资者、经济学家和市场分析师的研究框架。

目标不是复制观点，而是理解：

- 他们关注什么变量；
- 他们如何建立因果链；
- 他们为什么形成某个判断；
- 哪些假设最终被验证或证伪。

# Research Principle

优秀宏观研究不是预测所有事件，而是在不确定环境下建立：

- 清晰机制；
- 可验证假设；
- 风险边界；
- 动态调整能力。

Statistics Lab 的目标是吸收不同宏观思想，并通过数据和统计方法进行独立验证。
