# Institutional Macro Research Framework v1.0

# 机构宏观研究框架 v1.0

## 1. Purpose

本模块用于跟踪全球顶级投资机构、研究机构和宏观分析师的观点，将外部研究成果纳入 Global Macro Lab 的分析体系。

目标不是复制机构观点，而是：

- 理解不同机构的研究框架；
- 比较不同观点背后的假设差异；
- 判断哪些变量决定观点变化；
- 建立自己的独立判断。

# 6. Methodological Principle

机构观点不是事实，而是假设体系。

Statistics Lab 不记录：

“某机构认为市场会上涨。”

而记录：

“某机构基于哪些变量、哪些机制、哪些假设形成这一判断。”

最终目标：

建立从机构研究 → 独立分析 → 数据验证 → 自有观点的研究流程。
