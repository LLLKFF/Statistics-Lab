# Statistics Lab · Market Radar 日常报告

本目录保存盘后市场分析。每日完整报告按美股**交易日**命名为 `Market-Radar-YYYY-MM-DD.md`；日期指美东交易日，不是亚洲的生成日期。历史报告不覆盖。`2026-09-22` 是已完成的示例，不将该期标的和价位直接延用。

PDF 成品的版式、页序及核验要求见 [Market Radar PDF 设计规范](PDF-DESIGN.md)。

## 生成与核验

1. 查看纽约证券交易所交易日历，确认刚结束的美股常规交易日。休市日不生成新的常规盘后报告。盘后等待数据源的完整日线更新。先查看本目录是否已有该交易日 Radar，避免重复发布。
2. **先等同日宏观日报**：在 GitHub 确认 `docs/global-macro/05-research-diary/Global-Macro-Research-Diary-YYYY-MM-DD.md` 已写入且正文观察日与 Radar 目标交易日一致，读取完整报告及其中的事实、核心判断、关键数据、下一验证变量和来源。文件缺失或日期不一致时继续等待，不能用前一交易日的宏观结论代替；宏观日报 PDF/邮件发送进度不作为本步骤的依赖。
3. 用 `src/market-radar/asset_pool.csv` 的资产清单和 `src/market-radar/build_market_radar.py` 抓取日线，例如：`python src/market-radar/build_market_radar.py --output /tmp/market-radar-snapshot`。依赖：`yfinance>=0.2.65`、`pandas`、`numpy`。每次读取刚生成的 JSON 的 `status`、`coverage`、`generated_at_utc`、每行 `status` 和 `bar_date`。价格、EMA、成交量、ATR14、CMF20 与 OBV 均须重新计算；利率、美债期限、商品连续期货和加密资产留意数据口径。
4. **校验日期与覆盖**：SPY、QQQ、IWM 和拟推荐标的必须有该交易日的完整美股日线及必要指标。若数据仍是上一交易日、源失败或关键标的缺失，可尝试经验证的其他来源并注明来源差异；仍不能核实就说明未完成、暂不出交易候选，不复用昨天的结论。跨时区加密数据不能冒充同一时刻的美股收盘价。
5. 先读最近一期 Radar，复盘旧候选是否触发、失效或仍在等待，再依照当期数据重排。把**同日宏观判断 → 利率、美元、能源等传导变量 → 当期板块与标的的价量表现**串起来核对：只在宏观与盘面证据同时支持时提高方向优先级；若相互冲突，清楚写出分歧、验证条件和降低顺位的理由。宏观情景不是个股涨跌的已证实因果。OBV/CMF 只是价量压力代理，不是实际资金流；ATR14 衡量波动，不是固定止损或预测区间。所有关键价位都标明收盘日期及计算口径。
6. 撰写完整中文报告，**开头先给市场一句话理解、宏观背景下的执行顺序与多空优先级**（通常每个方向至多两只；无机会可空缺），每个候选写明选它的原因、触发条件、放弃条件及对应关键价位。正文增加“宏观判断如何映射到 Radar”的简短一节：说明同日宏观日报的观点、盘面是否验证、对哪些方向加分或减分、下一步何种数据会改变判断，并附同日宏观日报链接。后续章节展开指数、板块、核心标的、量价/OBV、ATR、主要反证和数据边界。用通俗语言解释现在看什么、什么时候动、什么时候不动；参照本目录的首期报告结构。不要把候选写成已经发生的交易信号，不保证收益。
7. 提交本期 `Market-Radar-YYYY-MM-DD.md` 到本目录，并更新下方索引；提交后重新读取 GitHub 文件确认写入。报告和日线快照标明数据截至时间与来源。若抓取不全，保留诊断并向用户说明，不发布貌似完整的分析。

## 报告结论区固定结构

**一句话市场状态**：同日宏观背景 + 指数方向 + 主线 + 广度/分歧；明确偏多、偏空还是观望，并区分宏观判断与盘面事实。

**执行顺序**：先看哪组指数/板块条件，再决定关注多头还是空头；条件均不成立就观望。

| 方向 | 顺序 | 标的 | 为什么优先 | 等什么再动 | 什么时候放弃 |
|---|---:|---|---|---|---|
| 多/空 | 1 | 当期标的 | 相对强弱、EMA、OBV/成交证据 | 市场同步条件 + 可核对的关键价位 | 失效条件 |

多头关注相对 SPY 强度、EMA 趋势及 OBV/量价确认；空头关注相对弱势、均线阻力与反抽失败，避免严重超跌后追空。对冲突指标和波动过大的标的降低顺位。按**条件清晰度**排序，不能简单按涨跌幅排名，也不能机械填满四只。
