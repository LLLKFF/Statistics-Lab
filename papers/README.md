# Papers

F｜论文与文献研究的主目录。这里不是 PDF 仓库，也不是摘要翻译库。

## 子目录

- `reviews/`：Paper Brief 与 Critical Review
- `replications/`：Replication Note
- `literature-maps/`：Literature Map
- `bibliography.bib`：统一引用库

## 编号与状态

- 单篇论文卡、精读或复现：`SL-PAPER-YYYY-NNN`
- 专题文献图谱：`SL-LIT-YYYY-NNN`
- 阅读状态：`Indexed`／`Reviewed`／`Replicated`／`Extended`

论文阅读状态不得替代原创研究的 `Prototype`／`Validated`／`Rejected` 状态。作者主张也不得写成 Statistics Lab 已独立验证的事实。
