# Foundations｜统计基础与理论工具

> 把博士阶段学习到的概率统计、随机模型和研究方法，沉淀为可检索、可复核、可应用的长期知识资产。

Foundations 对应 Statistics Lab 的 **G｜统计基础与理论工具**。它关注理论、条件、推导和概念连接，不把课堂笔记直接当作金融市场证据。

## 与其他模块的边界

| 模块 | 核心问题 | 典型产出 |
|---|---|---|
| G｜Foundations | 这个概念、定理或模型是什么，成立条件是什么？ | 概念笔记、推导、例题、模拟与知识图谱 |
| E｜Methods | 某种统计方法如何正确用于具体市场研究？ | 方法笔记、代码模板、实证案例与误用警示 |
| A–D｜Research | 某个市场命题是否得到数据支持？ | 可证伪研究、稳健性检验与证据判定 |
| F｜Papers | 既有论文的证据是否可信、能否复现？ | 论文卡、批判性精读、复现与文献图谱 |

理想链路是：

`基础理论 → 方法实现 → 论文证据 → Statistics Lab 实际研究`

## 知识地图

| 领域 | 建议目录 | 主要内容 |
|---|---|---|
| 概率论与测度基础 | `probability/` | 随机变量、分布、条件期望、收敛、极限定理与测度基础 |
| 数理统计与统计推断 | `mathematical-statistics/` | 估计、检验、充分性、信息量、渐近理论与重抽样 |
| 随机过程与随机模型 | `stochastic-processes/` | 马尔可夫链、鞅、布朗运动、泊松过程、随机微分方程 |
| 时间序列与金融计量 | `time-series/` | 平稳性、ARIMA、VAR、协整、波动率、状态空间与高频数据 |
| 回归与因果推断 | `econometrics-causal/` | OLS、面板、IV、DID、RDD、匹配、合成控制与识别假设 |
| 贝叶斯统计与计算 | `bayesian-computation/` | 先验、后验、MCMC、变分推断、模型比较与诊断 |
| 高维统计与机器学习 | `high-dimensional/` | LASSO、Elastic Net、稀疏因子、交叉验证与泛化 |
| 研究设计与可复现性 | `research-design/` | 预注册、多重检验、数据版本、实验记录与学术规范 |

目录在出现第一篇正式笔记时创建，不为保持空结构而添加占位目录。

## 内容类型

- **Concept Note**：定义、符号、直觉和适用边界；
- **Derivation Note**：公式推导及每一步所需条件；
- **Problem Note**：代表性例题、解法和易错点；
- **Simulation Lab**：用代码验证理论或有限样本性质；
- **Course Digest**：按课程或专题整理知识结构；
- **Method Map**：连接基础概念、统计方法、论文和实际研究。

同一篇笔记可以包含多个元素，但应指定一个主要类型。

## 编号与状态

### 编号

所有正式基础知识笔记使用：

`SL-FND-YYYY-NNN`

文件名建议为：

`sl-fnd-YYYY-NNN-short-title.md`

### 学习状态

- **Draft**：已建立结构，但公式、来源、例题或代码尚未完成复核；
- **Reviewed**：定义、条件、公式、来源和例题已经检查；
- **Applied**：已在至少一项 Methods 笔记或正式研究中实际使用，并附关联链接。

学习状态不得替代 Prototype／Validated／Rejected，也不使用 A–D 证据等级。

## 每篇笔记的必答问题

1. 这个概念解决什么问题？
2. 需要哪些前置知识？
3. 定义、符号和核心假设是什么？
4. 公式如何推导，每一步依赖什么条件？
5. 直觉上应该怎样理解？
6. 有哪些典型例题、反例或模拟结果？
7. 最常见的误用和适用边界是什么？
8. 如何连接到金融市场研究？
9. 关联哪些课程、教材、论文、方法笔记和 SL 研究？
10. 代码、随机种子、环境和复核记录是否完整？

新建笔记时复制[统一模板](../templates/foundation-note.md)。

## 工作流程

1. 从课程、教材、论文或研究问题中识别值得长期保留的知识点；
2. 分配 `SL-FND-YYYY-NNN` 编号并建立 Draft；
3. 补全前置知识、定义、假设、推导、直觉和例题；
4. 用模拟或代码检查关键结论；
5. 对照至少一个可靠来源复核符号、条件和结论；
6. 通过复核后更新为 Reviewed；
7. 当知识点进入 Methods 或正式研究时，添加双向链接并更新为 Applied；
8. 理论、教材版本或实际应用发生变化时保留修订记录。

## 红线

- 不无来源地复制教材、课件或他人笔记；
- 不省略定理、模型或估计方法成立的关键条件；
- 不把“看过”标记成 Reviewed，也不把“会计算”标记成 Applied；
- 不用漂亮推导代替数据检验；
- 不把基础理论直接包装成市场规律、预测或交易信号；
- 未核对的公式、例题和代码必须明确标记；
- 来源存在分歧时保留不同表述，并说明采用口径；
- 任何市场应用仍需进入 A–D 板块，独立完成研究登记、样本外与稳健性检验。
