# Statistics Lab

> **证据说话。** 用统计推断回答市场问题。

Statistics Lab 是一个独立的金融市场统计研究品牌：把市场上流行的说法、交易经验和因子逻辑转化为可证伪假设，用透明、可复现的方法判断证据强度。

当前规范版本：**v1.2**（2026-09-10）

## 我们研究什么

| 板块 | 核心问题 | 标准产出 |
|---|---|---|
| A｜市场假设的统计检验 | 这个市场说法是否得到数据支持？ | 检验报告 |
| B｜因果推断专题 | 价格变化由什么驱动，还是只有相关性？ | 因果识别报告 |
| C｜回测的统计陷阱 | 这个信号是真的，还是过拟合与偏差造成的？ | 陷阱拆解与失败案例 |
| D｜因子实证 | 这个因子是否具有稳定、可实现的超额收益？ | 因子验证报告 |
| E｜方法沉淀 | 这个统计方法如何正确用于市场研究？ | 方法笔记与代码模板 |
| F｜论文与文献研究 | 论文证据是否可信，能否复现并转化为自己的研究？ | 论文卡、精读、复现与文献图谱 |

共同原则：**做证据，不做预测。** 可以研究变量是否具有样本外预测信息，但不做具体点位预测、行情喊单或买卖信号推荐。

## 研究编号

- 原创研究：`SL-YYYY-NNN`
- 单篇论文卡、精读或复现：`SL-PAPER-YYYY-NNN`
- 专题文献图谱：`SL-LIT-YYYY-NNN`

研究状态使用 `Prototype`、`Validated`、`Rejected`；证据等级使用 A、B、C、D。状态描述研究走到哪一步，证据等级描述当前证据有多强，两者不能混用。

## 复现原则

每项正式研究应同时提供报告、可运行代码、数据说明、可重建图表、通俗版摘要、观点卡、关联论文与环境/版本记录。受许可限制的数据不进入仓库，只保留字段说明与获取方式。
