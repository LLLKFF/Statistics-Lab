# Statistics Lab

> **证据说话。用统计推断回答市场问题。**

**Statistics Lab** 是一个以统计学为核心方法，研究金融市场、全球宏观周期与资产价格形成机制的独立研究平台。

我们希望将市场中的经验、观点和叙事转化为可检验的问题，通过透明、可复现的方法评估证据强度。

当前规范版本：**v1.3**（2026-09-15）

---

# Research Philosophy

Statistics Lab 的核心原则：

> 不预测新闻，而理解机制。

研究关注：

- 一个市场观点是否可以被证伪；
- 一个变量是否具有稳定的信息价值；
- 一个策略是否具有统计意义；
- 一个宏观叙事背后是否存在可观察的传导机制。

共同原则：

**做证据，不做预测。**

可以研究市场变量是否具有样本外预测信息，但不提供具体点位预测、行情喊单或交易信号推荐。

# Global Macro Lab ⭐

Global Macro Lab 是 Statistics Lab 的核心研究模块之一。

## Mission

利用统计方法研究：

- 全球经济周期；
- 货币政策动态；
- 利率和债券市场；
- 美元体系与全球流动性；
- 宏观环境与资产价格关系。

## Core Framework

宏观研究统一分析链：

```
Economic Conditions

        ↓

Policy Response

        ↓

Financial Conditions

        ↓

Capital Flows

        ↓

Asset Prices
```

## Main Research Areas

### 1. Macro Regime Analysis

研究当前经济状态：

- Growth
- Inflation
- Liquidity
- Policy

识别不同宏观环境：

- Goldilocks
- Inflationary Growth
- Stagflation
- Deflationary Pressure

### 2. Monetary Policy Research

关注：

- Federal Reserve
- ECB
- BOJ
- PBOC

研究：

- Reaction Function
- Rate Cycle
- QE/QT
- Forward Guidance

### 3. Interest Rate Research

研究全球资产定价核心变量：

- Treasury Yield
- Yield Curve
- Real Yield
- Term Premium

### 4. Global Liquidity

研究：

- Dollar Cycle
- Global Financial Cycle
- Cross-border Capital Flow

### 5. Macro Asset Allocation

研究宏观因素如何影响：

- Equity
- Fixed Income
- FX
- Commodity
- Gold
- Crypto

# Reproducibility Principle

每项正式研究尽可能提供：

- 研究报告；
- 可运行代码；
- 数据说明；
- 可重建图表；
- 方法说明；
- 环境和版本记录。

受许可限制的数据只保留字段说明和获取方式。
